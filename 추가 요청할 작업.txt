남아있는 작업

1. 빠른입력 수정할수 있도록 편집 버튼을 만들어줘. 편집 버튼은 빠른 입력 메뉴 하나당 개별로 하거나, 편집을 누르면 전체 빠른 입력 메뉴들을 수정하는 방법중에 효율적인 방법으로 만들어줘

2. 빠른 입력 저장 버튼은 하나만 필요해. 입력 완료 아래에 있는 버튼만 있으면 됨

3. 외화, 법인, 주식, 연금. 포인트, 병훈급여, 아름급여 섹션에 경로에 있는 엑셀 파일을 확인해서 해당되는 항목에 업데이트 해줘

4. 설정 화면에서 대분류 또는 하위 분류를 삭제할때 분류에 포함되는 거래내역들은 다른 분류로 대체할 건지 물어본 후에 삭제를 하도록 해줘

5. 섹션 목록을 스크롤 내리지 않고 보도록 해줘

6. 메뉴-거래 내역 화면 내용검색 찾기는 내용 항목에서만 찾도록 변경해줘

7. 메뉴-비용/수익 화면의 카테고리별 항목을 클릭했을때 지출 카테고리는 대상기준, 수입 카테고리는 출처 기준으로 검색이 되는지 확인해주고 포인트 작성된 내용들이 검색에서 누락되고 있으니 확인해줘

8. 모든 메뉴 오른쪽에 나오는 거래내역들은 마우스로 클릭 또는 드래그 해서 다중선택 할 수 있도록 해주고 갯수와 합계 금액을 보여줘. 그리고 날짜 내림차순 형태로 정열해줘

9. 설정을 포함한 메뉴의 모든 화면에서 대분류 및 항목 그리고 거래내역을 삭제할땐 경고 창을 띄워서 다시 한번 물어봐줘

10. 거래내역 내용을 입력할때 과거에 입력했던 정보가 있으면 항목 자동 생성 기능을 드롭다운 형태로 보여줘서 선택할 수 있게 해주고 선택을 하면 마지막 거래의 금액과 대상 출처를 자동 입력해줘

11. 섹션별로 화폐를 원화와 달러 둘중에 하나를 선택할 수 있게 해주고 달러로 선택된 섹션은 실시간 환율을 참고해서 원화로도 표시해줘

12. 섹션간 거래 금액 이동 기능 추가. 내용에 섹션이동을 입력하면 섹션간 대상과 출처를 입력할 수 있도록 만들어줘.

13. 대상 또는 대변은 입금, 출처 또는 차변은 출금으로 텍스트 변경
