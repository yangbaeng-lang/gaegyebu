연금차트 직접투자 비중 탭 - 자산군 추가 가이드
============================================================

수정 파일 경로:
  app/pension-charts/allocation/page.tsx

------------------------------------------------------------
수정해야 할 세 군데
------------------------------------------------------------

[1] CATEGORY_RULES (23번 줄 근처)
    - 역할: 자산명에 키워드가 포함되면 해당 자산군으로 분류
    - 수정 방법: 새 줄 추가

    예시:
      { keyword: '내가찾을키워드', category: '새자산군이름' },

    주의:
      - keyword는 실제 자산 상품명의 일부 문자열
      - 위에서부터 순서대로 매칭되므로 구체적인 키워드를 위에 배치
      - 어떤 키워드에도 안 걸리면 자동으로 '미분류' 처리됨


[2] CATEGORY_ORDER (32번 줄 근처)
    - 역할: 차트에서 자산군이 표시되는 순서
    - 수정 방법: 원하는 위치에 새 자산군 이름 삽입
    - '미분류'는 항상 맨 마지막에 유지

    예시:
      const CATEGORY_ORDER = ['S&P500', '나스닥', '반도체', '새자산군이름', 'TDF', ...]


[3] CATEGORY_COLORS (34번 줄 근처)
    - 역할: 각 자산군의 색상 지정
    - 수정 방법: 새 항목 추가

    예시:
      '새자산군이름': '#색상코드',

    참고 색상 (현재 미사용):
      파랑  #3b82f6
      초록  #22c55e
      빨강  #ef4444
      분홍  #ec4899
      연두  #84cc16
      하늘  #38bdf8
      라임  #4ade80

------------------------------------------------------------
실제 추가 예시 (우주 자산군)
------------------------------------------------------------

CATEGORY_RULES에 추가:
  { keyword: 'TIGER미국우주테크', category: '우주' },

CATEGORY_ORDER에 추가:
  ['S&P500', '나스닥', '반도체', '우주', 'TDF', '다우존스', '금', '미분류']

CATEGORY_COLORS에 추가:
  '우주': '#7c3aed',

------------------------------------------------------------
주의사항
------------------------------------------------------------

- 자산군 이름은 세 군데(CATEGORY_RULES, CATEGORY_ORDER, CATEGORY_COLORS)
  모두 동일한 문자열이어야 함
- 실제 상품 데이터는 설정 페이지(app/settings)에서 추가
- 코드 수정 후 개발 서버를 재시작해야 반영됨
